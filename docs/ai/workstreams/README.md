# Workstreams

This folder tracks active schema initiatives that span multiple rounds, repos, or apps.

Use a workstream when a task needs:
- durable scope
- protected constraints
- a decision log
- a validation checklist
- a round-by-round change ledger

## Standard structure

Each workstream should contain:
- `README.md`
- `decision-log.md`
- `change-ledger.md`
- `validation-checklist.md`

Optional files:
- `implementation-plan.md`
- `references.md`
- `prompt-recipes.md`

## Current workstreams
- `schema-repo-operations/`

## Working rule

If a task is likely to continue across several sessions, add or update a workstream folder before making large schema changes.
