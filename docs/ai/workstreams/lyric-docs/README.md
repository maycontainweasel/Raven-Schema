# Lyric Docs

This workstream tracks the new sibling interactive documentation app for the Schema v1 / Lyric v2 program.

It is not primarily a marketing site.

It is a working proving ground for:
- documentation
- capability demos
- live generator validation
- runtime verification
- architecture feedback

## Purpose

Lyric Docs should let a person or an AI move through the platform one capability at a time and see:
- the authored input
- the compiled spec
- the generated artifacts
- the runtime behavior
- the expected Nuxt-facing surface
- the result of verification

## Relationship to current apps

- `schema-docs/` remains a useful reference and input surface.
- `lyric-docs/` is the new sibling app intended to become the clearer long-term documentation and proving-ground experience.

## First deliverable

The first deliverable is a capability-driven app structure, not a full polished product.

The app should prove that the system can explain and execute:
- a simple model
- a field
- a field-type change
- a CRUD path
- a relation
- a taxonomy
