# Schema v1.5

This workstream tracks the deliberate hardening phase between the current Schema v1 baseline and the longer-term Lyric v2 redesign.

Use this workstream for improvements that should land in the current platform without waiting for v2, especially when they:
- simplify contracts
- reduce generator ambiguity
- tighten runtime boundaries
- make agent behavior more predictable
- improve verification and rollout safety

## Focus

Schema v1.5 is the hardening lane for:
- record-id and request-shape clarity
- shared utility-function contracts
- frontend-to-router request discipline
- clearer recipes and skill-driven implementation paths
- safer defaults for tenant adoption
