# Anti-Patterns

This folder collects known bad patterns that agents and humans should avoid in the current Schema v1.5 hardening lane.

Use it for:
- generator mistakes
- router/request mistakes
- helper misuse
- runtime patterns that repeatedly cause fragile behavior

## Working rule

If a pattern causes confusion more than once, document it here and create or update a skill/checklist so future agents are forced onto the safer path.
