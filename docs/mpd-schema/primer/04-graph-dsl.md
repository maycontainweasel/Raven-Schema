Title: Graph DSL (MPDG) Primer
Scope: global
Applies to: MPDG
Depends on: docs/graph-dsl-profile.md, docs/mpdg-tag-glossary.md

The MPDG file (`config/graph.mpdg`) is the primary schema definition.

It defines:
- tables and fields
- CRUD + routers
- views + Typesense
- relations + edges
- taxonomies + terms
- instance/post capabilities
- edge helper utilities (dynamic relation CRUD)
- module overlays

For detailed syntax, see:
- `docs/graph-dsl-profile.md`
- `docs/mpdg-tag-glossary.md`
