# Helios UI Layer

Shared UI primitives and field components for Helios-based apps.

## Scope

- Ark UI-based primitive fields (`AInput`, `ASelect*`, `ANumberInput`, `ATagsInput`, etc.).
- Tree primitives (`ATree`) and reusable low-level UI components.
- No admin model-management workflows.

## Intended usage

Load after `helios` and before `helios-admin`:

1. `helios`
2. `helios-ui`
3. `helios-admin`
