# Lyric Docs

This folder is reserved for the new sibling interactive documentation app.

It should become the live proving ground for:
- capability-by-capability documentation
- generated artifact inspection
- runtime verification
- demo flows that expose what the platform actually does

## Status

- planning and structure only
- no app scaffold yet

## Role

Lyric Docs is intended to:
- harden Schema v1
- inform Lyric v2
- replace vague documentation with working, inspectable examples
